# Jarvis Voice v1

## 本轮修改摘要

- API 前缀统一为 `/p/jarvis`，健康检查改为无 token 的 `GET /p/jarvis/v1/models`，对话模型与线上模型列表统一为 `jarvis`。
- 新增登录、退出及 401 会话过期处理，凭证使用 `jarvis-token` / `jarvis-username`。
- 使用 `MediaRecorder` 生成 `audio/webm`，停止后提交 `/asr`。
- ASR 非空结果自动进入流式对话，完整回复后调用 Edge TTS 播报；POST 遇到现网 405 时兼容回退 GET。
- 状态机统一为 `idle → recording → transcribing → thinking → speaking`。
- 保留深空 Canvas 背景，新增中央录音按钮和实时识别/回复区域。
