# v10

## 修改摘要

- MID_TEXT 每次仅取 `text` 数组中最后一个非空候选，直接替换实时识别区域。
- 删除中间文本追加与拼接逻辑，支持识别结果变短或改写时直接校正。
- 新文本与当前显示完全一致时跳过状态更新，避免 320ms 重复响应导致无效渲染和视觉抖动。
- FIN_TEXT 进入用户消息并完成当前回合后，清空识别文本区域，恢复监听提示。
