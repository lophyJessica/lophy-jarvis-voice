## 3. 部署流程

### 3.1 前端部署（用户发 jarvis-voice.zip）

```
收到 zip（dist 内容）→ 部署到 /var/www/pmlophy.com/jarvis-voice/
步骤：
1. 解压检查（index.html + assets/index-*.js + pcm-capture-worklet.js）
2. 路径修正：/assets/ → ./assets/（相对路径，子路径部署）
3. /api-server → /p/jarvis（API 前缀）
4. addModule("/pcm-capture-worklet.js") → addModule("./pcm-capture-worklet.js")
5. 替换部署目录
6. curl 验证 200 + 检查新 bundle hash
```

### 3.2 后端部署（用户发 jarvis-asr-stream.zip）

```
1. 备份当前 /opt/jarvis-asr-stream.py（.bak-时间戳）
2. 替换为新版
3. python3 -m py_compile 语法检查
4. systemctl restart jarvis-asr-stream
5. systemctl is-active 确认
6. 契约自测（test-asr-stream.py）
7. 浏览器实测（用户验收）
```

### 3.3 网关（Hermes）重启

```
systemctl --user restart hermes-gateway && bash /root/hermes-wait.sh
- 等 30 秒再判断（重启有十几秒延迟，不是挂了）
- 判断标准：systemctl is-active 和日志，不看飞书提示
- 用户手动重启，我不代劳；重启前备份
```

## 4. 配置位置（改前必读）

| 配置 | 位置 | 说明 |
|---|---|---|
| 前端环境 | .env.example → .env.local（本地） | VITE_HERMES_API_URL 等 |
| Hermes 主配置 | /root/.hermes/config.yaml | providers/multiplex/auxiliary.vision |
| jarvis profile | /root/.hermes/profiles/jarvis/config.yaml | 模型/vision，与主配置同等级 |
| 密钥 | /root/.hermes/.env | DEEPSEEK/AWESOMEAI/API_SERVER_KEY 等 |
| 记忆系统 | memory.provider: holographic | 本地 SQLite，无配额限制 |
| systemd 服务 | /etc/systemd/system/jarvis-*.service | 各服务配置 |
| nginx | /etc/nginx/ | 反代路由 |

## 5. 模型配置（当前）

```
杰西卡（主 profile）与罗宾（jarvis profile）对称：
主模型: deepseek-v4-flash（DeepSeek 官方直连）
兜底: custom:awesomeai gpt-5.6-luna
vision: gemini-3.1-flash-lite（auxiliary.vision）
```

坑：
- provider 引用须带 custom: 前缀（裸名报 Unknown provider）
- profile 完全隔离（配置+密钥不继承主配置）
- profile 绝不能有 API_SERVER_KEY/PORT/CORS（会触发 multiplex skip）
- HERMES_PROFILE=jarvis hermes config set 会写主配置非 profile（用 python yaml 改 profile）

## 6. 记忆系统（Holographic）

- provider: holographic（本地 SQLite ~/.hermes/memory_store.db）
- 三层检索：FTS5 全文 + HRR 向量 + 实体/信任评分
- fact_store 操作：add/search/probe/related/reason/contradict/update/remove/list
- fact_feedback：点赞/踩影响信任评分，被踩多自动遗忘
- 双通道分工：内置 memory（MEMORY.md，快捷上下文自动注入）+ fact_store（深层知识语义搜索）
- 切换命令：hermes config set memory.provider holographic
