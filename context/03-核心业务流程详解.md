## 1. 登录流程

```
用户打开 /jarvis-voice/
  → 检查 localStorage 是否有 jarvis-token
  → 有 token：POST /p/jarvis/auth/verify 校验
      → 有效：进入主界面
      → 401：清 token 回登录页「登录已过期」
  → 无 token：显示登录页
  → 输入 username + password
  → POST /p/jarvis/auth/login
  → 成功：返回 { ok:true, token, username }，存 localStorage
  → 进入主界面，GET /p/jarvis/history 拉取记忆
```

关键点：
- 密码 VPS 后端 SHA256(salt+password) 校验（users.json 键名 `hash`）
- 登录响应**必须含 ok:true**（前端 `!w.ok` 判失败）
- token TTL 7 天；改密后旧 token 全部失效
- verify 支持 GET+POST 双路由（nginx auth_request 用 GET 子请求）
- isDev（localhost/127.0.0.1）：跳过登录直接进主界面

## 2. 语音实时对话流程

### 2.1 状态机

```
idle(listening) → recording → transcribing(实时出字) → thinking → speaking → idle
        ↑_____________________打断________________________|
```

### 2.2 详细步骤

**阶段一：监听（idle）**
1. 页面加载 → getUserMedia({audio:true}) → AudioContext
2. AnalyserNode 实时分析音量（getByteTimeDomainData）
3. 音量超阈值持续 300ms → 判定「开始说话」

**阶段二：录音 + 流式识别（recording → transcribing）**
1. 触发 AudioWorklet 采集（128 帧/批，16k 重采样，Float32→Int16）
2. POST /asr-stream/start 创建会话（拿 session_id）
3. 每 320ms 累积一批 PCM（约 10240B）→ POST /asr-stream/chunk
   - header: X-Session-Id + Content-Type: audio/pcm
   - VPS 端 PCM 直通百度（16k/mono/s16le）
4. 响应 text 为**单调增长字符串**（定稿句 + 当前句 MID）→ 打字机逐字展示
   - 注意：百度 MID 是整句修订，前端做前缀扩展展示，不追加
5. 循环直到静音

**阶段三：结束识别（→ thinking）**
1. 音量低于阈值持续约 7s（VAD 静音分段，阈值 0.036 可调）→ 判定「说完」
2. POST /asr-stream/end → 拿 FIN_TEXT 最终文本（收尾以此为准发送）
3. 清空「识别中」区 → 最终文本作为用户消息进列表

**阶段四：对话（thinking）**
1. 用户消息 + 历史 → POST /p/jarvis/v1/chat/completions（Bearer token）
2. SSE 流式接收回复 → 实时渲染（markdown）
3. 显示「停止思考」按钮（AbortController 可中断）

**阶段五：播报（speaking）**
1. 回复文本 → 句子切分 → GET /tts?text=URL编码 → MP3
2. 流式按句播放（台湾腔），可停止
3. VAD 持续监听：检测到用户说话 → audio.stop()（打断）→ 回 recording

**阶段六：记忆同步**
1. 每轮完整对话结束 → POST /p/jarvis/history（完整列表.slice(-200)）
2. 失败静默（console.error），Dexie 本地兜底

### 2.3 降级路径

```
AudioWorklet 初始化失败
  → 回退 MediaRecorder（audio/webm）
  → 停止后整段 POST /asr（百度短语音）
  → 识别结果一次性显示（无实时出字，但可用）
【必须保留此路径】
```

### 2.4 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| VAD 默认阈值 | 0.036 | 音量触发，滑块可调 |
| 说话判定 | 300ms 连续超阈 | 开始录音 |
| 静音判定 | ~7s 连续低阈 | 结束录音 |
| PCM 批次 | 320ms ≈ 10240B | 上传间隔 |
| PCM 格式 | Int16 LE 16kHz mono | 百度要求 |
| 百度帧 | 160ms = 5120B | 每帧 |
| 建连超时 | 6s | 百度 WS |
| chunk 超时 | 30s | 前端流式请求 |
| 对话/ASR/TTS 超时 | 120s（12e4） | 大请求 |
| 会话 TTL | 60s | VPS 无活动回收 |

### 2.5 VPS 后端健壮性（Opus 重构版）

- 断连自动重连：接收循环异常时保留已定稿文本，下个 chunk 用新 sn 重建连续传
- 会话超时清理：后台任务定期回收 TTL 内无活动会话
- 单会话 chunk 串行（asyncio.Lock），跨会话并发互不影响
- chunk 永不返回 5xx：异常降级为 {ok:true, text:已有文本}，避免前端回退 webm
- 连续建连失败 3 次后该会话不再重试

## 3. 跨浏览器记忆流程

### 3.1 初始化

```
登录成功 → GET /p/jarvis/history?limit=50
  → 云端记录作为消息列表初始数据
  → 加载中显示「同步中…」
  → GET 失败 → Dexie IndexedDB 缓存兜底
```

### 3.2 写入

```
每轮对话结束（用户消息+罗宾回复都生成后）
  → POST /p/jarvis/history（body: {messages: 完整列表.slice(-200)}）
  → 失败静默
```

### 3.3 注意

- 初始化 GET 完成前**禁止 POST**（避免覆盖云端）
- 不用 messages 变化的 useEffect 自动 POST（防竞态）
- 显式在对话轮次结束后 POST 一次

## 4. 图片识别流程

```
粘贴图片（Ctrl+V）
  → canvas 压缩（max-width 800px, JPEG quality 0.6）
  → 缩略图显示在输入框
  → 发送时 content 构造：
    [ {type:"text", text:"用户文字"},
      {type:"image_url", image_url:{url:"data:image/jpeg;base64,..."}} ]
  → POST /p/jarvis/v1/chat/completions
  → Hermes 检测到 image_url → vision_analyze 工具
  → Gemini-3.1-Flash-Lite 识别图片 → 文字描述
  → 主模型（DeepSeek）基于描述回答
```

关键点：
- 图片必须 content[] 数组格式（非 Markdown ![图片]）
- vision 辅助模型配置在 auxiliary.vision（主配置 + jarvis profile 两处）
- 前端超时 120s（识别 10-15s + 传输）

## 5. 文档识别流程

```
粘贴/上传文档（40+ 类型：pdf/docx/xlsx/txt/md/html/yaml/json/js/ts/tsx/css/py/zip/图片等）
  → 文件进待发送 chip（不自动发送）
  → POST /p/jarvis/file/upload（字段 file + 头 X-Jarvis-User）→ 返回 {path}
  → 用户输指令后发送，消息 content 构造：
    [ {type:"text", text:"【用户指令】<指令>"},
      {type:"text", text:"【文档内容】<文件名>：\n请读取文件 <path> 并处理以上指令。"} ]
  → Hermes 收到 → 用工具读取 path → 基于文档内容回答
```

展示层规则：
- 前端只显示 📄 文件名 + 用户指令（不渲染文档全文/路径）
- 历史旧消息兼容：正则解析【用户指令】…【文档内容】拼接格式
- 罗宾回复中不提及/展示文件路径、文件名

## 6. TTS 播报流程

```
回复文本 → ttsSentences 切句
  → 逐句 GET /tts?text={encodeURIComponent(句)}
  → VPS 8866 Edge TTS（zh-TW-HsiaoChenNeural）
  → 返回 MP3 → 预取 3 段流水线 → Audio 流式播放
  → 播放循环 catch 用 continue 跳过坏段（不中断全部）
  → finally 兜底清播放状态
  → 播放中 VAD 检测到说话 → audio.pause() 打断
```

## 7. 异常处理

| 场景 | 处理 |
|---|---|
| asr-stream start 失败 | 前端报「流式识别启动失败」，降级整段 /asr |
| asr-stream chunk 失败 | 静默重试一次，仍失败降级 webm |
| 对话 401 | 清 token 回登录页「登录已过期」 |
| TTS 失败 | 静默，文字回复仍显示 |
| 记忆 POST 失败 | console.error，Dexie 兜底，不影响界面 |
| AudioWorklet 失败 | MediaRecorder 降级 |
| 文档上传失败 | 提示错误，消息不进队列 |
