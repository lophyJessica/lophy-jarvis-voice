## 6. 维护时的高频陷阱

1. **v114 是最新**：versions/ 有 114+ 个目录，改代码前先确认当前基线（AGENTS.md「当前状态」）
2. **ASR 契约**：start→{ok,session_id} / chunk→{ok,text:单调增长文本} / end→{ok,text:最终}；chunk 用 X-Session-Id 头，end 用 JSON body
3. **百度 WS 必须带 sn**：URL ?sn=uuid，漏了返回 HTTP 200 不升级
4. **不提交不推送**：除非用户明确要求；部署由用户确认后执行
5. **打包**：npm run build 后更新根目录 jarvis-voice.zip，汇报写明 zip mtime
