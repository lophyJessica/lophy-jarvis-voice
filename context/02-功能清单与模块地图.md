# 02-功能清单与模块地图

## 1. 功能清单

### 1.1 公共能力（两模式共享）

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F01 | 登录认证 | 5 账号 + 密码 + VPS 后端校验（SHA256 哈希） | ✅ |
| F02 | 用户隔离 | 每用户独立 history-{username}.json | ✅ |
| F03 | 跨浏览器记忆 | GET/POST/DELETE /p/jarvis/history | ✅ |
| F04 | markdown 渲染 | marked + DOMPurify + 代码块复制 | ✅ |
| F05 | 消息复制 | 每条消息 hover 复制按钮 | ✅ |
| F06 | 图片识别 | 粘贴图片 → content[] → Gemini 识别 | ⬜ 融合补齐 |
| F07 | 文本输入框 | textArea 多行输入 + 一键复制 | 🚧 融合用文字版控件 |
| F08 | 深空星云背景 | Canvas 动画（star 93 + sphere 49） | ✅ |
| F09 | 手机端适配 | 响应式布局（>768 桌面 / ≤768 手机） | ⬜ 融合做 |

### 1.2 语音模式

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| V01 | VAD 免按钮 | Web Audio 音量检测（阈值 0.02-0.05，静音 1.5s 分段） | ✅ |
| V02 | AudioWorklet PCM | 128 帧采集、16k 重采样、Float32→Int16 | ✅ |
| V03 | 百度流式 ASR | 320ms 批次上传 → MID_TEXT 实时出字 | ✅ |
| V04 | 整段降级 | MediaRecorder webm → /asr 整段识别（兜底） | ✅ |
| V05 | Edge TTS 播报 | 台湾腔 HsiaoChenNeural | ✅ |
| V06 | 打断 | 播报中说话 → audio.stop() 立即停 | ✅ |
| V07 | 停止思考按钮 | thinking/speaking 可中断（AbortController） | ✅ |

### 1.3 文字模式

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| T01 | 打字对话 | textArea 输入 + 发送 | ✅ |
| T02 | 图片粘贴 | Ctrl+V 粘贴截图（canvas 压缩 800px/JPEG 0.6） | ✅ 文字版 |

### 1.4 模式切换（融合新增）

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| M01 | 模式切换按钮 | 顶部切换 🎤语音 / ⌨️文字 | ⬜ |
| M02 | 模式持久化 | localStorage 记住上次模式 | ⬜ |

## 3. 依赖关系

```
登录（F01/F02） ← 前置
    ↓
主界面（MainShell）
    ├── 记忆同步（F03）← 登录后自动 GET
    ├── 语音链路（V01-V07）← AudioWorklet 优先，MediaRecorder 降级
    ├── 渲染（F04/F05）← 对话回复后
    └── 图片（F06）← 粘贴触发
```
