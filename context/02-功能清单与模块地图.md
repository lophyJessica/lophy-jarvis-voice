## 2. 模块地图（实际代码结构）

```
src/
├── main.tsx                    # 入口（无 React Router，条件渲染）
├── App.tsx                     # 主框架：登录态 + 双模式 + ChatArea + Composer
├── auth.ts                     # token 管理 / verify / 401 处理器
├── db.ts                       # Dexie IndexedDB 本地兜底
├── components/
│   ├── LoginPage.tsx           # 登录页
│   ├── ChatMessageRow.tsx      # 消息行（用户/罗宾，复制按钮）
│   ├── MessageRichContent.tsx  # markdown 富文本渲染
│   └── JarvisCore.tsx          # 对话核心（SSE 流式）
├── api/
│   ├── asrStream.ts            # 流式 ASR 契约客户端（start/chunk/end）
│   ├── docUpload.ts            # 文档上传（file/upload）
│   ├── hermes.ts               # 对话 API（streamChatCompletion）
│   ├── history.ts              # 跨浏览器记忆同步
│   └── request.ts              # 请求封装（超时/错误）
├── hooks/
│   ├── useVoiceActivityDetector.ts  # VAD（音量检测）
│   ├── useStreamingAsr.ts           # 流式 ASR 主逻辑
│   ├── useMediaRecorder.ts          # 整段降级
│   ├── useSpeechRecognition.ts      # 浏览器原生识别（备用）
│   ├── useSpeechSynthesis.ts        # TTS 播报
│   ├── useTypewriterFollowAlong.ts  # 打字机逐字跟嘴
│   └── useTts.ts                    # TTS 播放循环
├── utils/
│   ├── markdown.ts             # marked + DOMPurify
│   ├── asrCorrect.ts           # ASR 纠错（客户端）
│   ├── ttsSentences.ts         # 句子切分
│   ├── images.ts               # 图片压缩
│   └── clipboard.ts            # 复制
└── types/
    ├── messages.ts             # content[] 消息类型 + 文档标签解析
    └── speech.d.ts
public/
└── pcm-capture-worklet.js      # AudioWorklet PCM 采集（128帧/16k重采样）
server/
├── jarvis-asr-stream.py        # 百度流式 ASR 代理（Opus 重构版，VPS 8869）
└── test-asr-stream.py          # ASR 契约自测脚本
versions/                       # 版本快照（v1~v114+，每次修改复制，不删除）
```

## 3. 依赖关系

```
登录（F01/F02）← 前置
    ↓
主界面（双模式）
├── 语音模式：VAD → AudioWorklet PCM → asr-stream(start/chunk/end) → 百度 MID
│                    └─ 失败 → MediaRecorder → /asr 整段
├── 文字模式：textArea + 图片/文档粘贴 → content[] 组装
├── 对话：content[] → /p/jarvis/v1/chat/completions → SSE → markdown 渲染
├── 播报：回复 → /tts → MP3 流式播放（可打断）
└── 记忆：对话轮次结束 → POST /p/jarvis/history（Dexie 兜底）
```

```

/tts                   ─────────→  8866 (jarvis-tts.py, Edge TTS)
```
