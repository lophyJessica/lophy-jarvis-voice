# 01-业务背景与项目范围

## 1. 业务背景

### 1.1 起源

用户（路飞/Lophy）从 2026-07 起构建个人 AI Agent"罗宾"（Robin），经历三个阶段：

1. **文字版（lophy-jarvis）**：Web 控制台，登录 + 聊天 + 跨浏览器记忆 + 图片识别
2. **语音版（lophy-jarvis-voice）**：独立项目 AB 并行，VAD 免按钮 + 百度流式 ASR + Edge TTS 播报
3. **融合版（目标）**：单一入口、双模式（语音实时对话 / 文字思考）、一套记忆

### 1.2 为什么做罗宾

- 个人 AI 助理，区别于飞书（工作协作）/微信（社交）
- 核心价值：**对话即操作**——问、看、听、办
- 三端定位：路飞（用户本人）、罗宾（网页端 AI）、杰西卡（飞书端助手）
- 产品理念：一个大脑（Hermes + 模型），多个入口（网页/语音/飞书），共享记忆

### 1.3 技术背景

- 大脑：VPS Hermes API Server（8642）+ 模型（DeepSeek 官方直连主模型 + Gemini 视觉辅助）
- 记忆：VPS 8868 服务，每用户独立 history-{username}.json
- 识别：百度流式 ASR（wss://vop.baidu.com/realtime_asr，VPS 代理 8869）
- 播报：Edge TTS（VPS 8866，台湾腔 zh-TW-HsiaoChenNeural）
- 前端：React 19 + TS + Vite，部署于 https://pmlophy.com/jarvis-voice/

## 2. 项目范围

### 2.1 本项目（lophy-jarvis-voice）

**语音版核心能力：**

| 模块 | 能力 |
|---|---|
| 语音输入 | VAD 免按钮（说话自动开始/静音自动结束） |
| 流式识别 | AudioWorklet PCM 直采 → 百度流式 → 边说边出字 |
| 语音播报 | Edge TTS 回复朗读，可打断 |
| 对话 | Hermes API（DeepSeek 主模型） |
| 记忆 | 跨浏览器/跨版本同步（共用 8868） |
| 渲染 | markdown + 代码块复制 + 消息复制 |
| 认证 | 登录 + 用户隔离 + token 校验 |

### 2.2 范围外（本期不做）

- ❌ 多会话管理（二期）
- ❌ 文档识别 PDF/Word/Excel（二期）
- ❌ 注册功能（固定 5 账号）
- ❌ PWA 离线（二期）
- ❌ APK 打包（融合完成后二期）

### 2.3 与文字版的关系

| 维度 | 文字版 | 语音版（本） |

**终局**：融合为单一入口、双模式（语音/文字切换），文字版退役。

## 4. 关键约束

1. **物理隔离**：本项目禁止碰文字版代码
2. **降级保护**：MediaRecorder 整段识别路径必须保留
3. **版本快照**：每轮修改入 versions/v{n}/
4. **浏览器自查**：AI 改完必须自己开浏览器验证
5. **成本敏感**：主模型走 DeepSeek 官方直连（稳定省钱），中转仅 vision 用

## 5. 验收标准（融合前基线）

- [ ] VAD 免按钮对话：说话即识别，实时出字（延迟 <1s）
- [ ] 打断：播报中说话立即停止进入新回合
- [ ] 跨浏览器记忆：换浏览器记录不丢
- [ ] markdown 渲染 + 复制：代码块/列表/粗体正常
- [ ] 登录 + 用户隔离：5 账号互不可见
- [ ] 图片识别：粘贴截图 → 描述（融合后）
- [ ] 模式切换：语音/文字一键切换（融合后）
