### 4.1 流式指标（验收判定）

| 指标 | 健康标准 | 问题信号 |
|---|---|---|
| chunk× | 10-25+ | 很低 → 代理/会话问题 |
| 流式命中× | >0，边说边涨 | 恒 0 → chunk text 空 |
| 源 | stream | webm → 流式未工作 |
| 预览× | ≈0 | 很高 → 流式死了走旧逻辑 |
