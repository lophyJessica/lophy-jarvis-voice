## 迭代 PRD 规范

1. 文件名：`robin-text-iter-v{n}.md`（n 递增）
2. 开头标注：迭代日期、目标、影响模块
3. 内容对齐主 PRD 的编号体系（T01-T03 / F01-F10）
4. 每轮迭代只写**本轮改动**，不重复主 PRD 内容
5. 完成后回写主 PRD 状态（如功能状态从 ✅ 更新）
