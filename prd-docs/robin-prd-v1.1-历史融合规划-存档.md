## 3. 页面结构

```
LoginPage（登录，手机端卡片式布局）
└── MainShell（主框架）
    ├── Header：模式切换 + 用户信息 + 退出
    ├── ChatArea：消息列表（markdown 渲染 + 复制）
    ├── VoicePanel（语音模式）：状态光圈 + 实时识别文本
    ├── TextInput（文字模式）：textArea + 复制 + 发送
    └── Canvas：深空星云背景
```

## 4. 响应式要求（F09 手机端适配）

| 断点         | 布局                                          |
| ---------- | ------------------------------------------- |
| >768px（桌面） | 现有布局：侧边/顶部 Header + 消息区 + 输入区               |
| ≤768px（手机） | 单列全屏：Header 紧凑、消息区占满、输入区贴底（安全区适配）、模式切换按钮可触达 |
| 手机端语音      | 大号录音按钮（拇指可点）、VAD 自动模式优先                     |
| 手机端文字      | textArea 自适应高度、发送按钮右侧、键盘弹出时布局不塌             |

## 5. 状态机

```
idle(listening) → recording → transcribing(实时出字) → thinking → speaking → idle
            ↑___________________打断___________________|
```

## 6. 数据流

```
输入（语音/文字）→ 识别/提交 → POST /p/jarvis/v1/chat/completions（token）
  → 回复 → 渲染 markdown + 复制 → TTS 播报（语音模式）
  → 每轮结束 → POST /p/jarvis/history（跨浏览器记忆）
```

## 7. 接口清单

| 接口                                   | 方法              | 用途            |
| ------------------------------------ | --------------- | ------------- |
| /p/jarvis/auth/login                 | POST            | 登录            |
| /p/jarvis/v1/chat/completions        | POST            | 对话（带 token）   |
| /p/jarvis/history                    | GET/POST/DELETE | 记忆同步          |
| /p/jarvis/asr-stream/start·chunk·end | POST            | 流式识别（VPS 已就绪） |
| /tts                                 | GET             | Edge TTS 播报   |
